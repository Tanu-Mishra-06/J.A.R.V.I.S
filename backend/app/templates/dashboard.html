AIOps Machine Learning & Statistical Architecture Guide

J.A.R.V.I.S. integrates 4 distinct, complementary algorithms engineered specifically for operational telemetry (logs, metrics, and distributed traces) to detect anomalies and perform explainable root cause analysis without black-box hallucination.

MODEL 1 Univariate Baseline

Dynamic Rolling Z-Score

Maintains rolling window mean σ and variance μ to detect instant metric shocks.

z = (x_t - μ_w) / σ_w ≥ 2.5
  • • Window Size: 10 rolling points
  • • Threshold: 2.5 standard deviations
  • • Strengths: Zero warmup training, O(1) streaming latency
MODEL 2 Multivariate ML

Isolation Forest Ensemble

Unsupervised decision tree forest isolates anomalous combinations of CPU, RAM, and latency.

s(x, n) = 2^(-E(h(x)) / c(n))
  • • Estimators: 100 Isolation Trees
  • • Contamination (ν): 0.08 (tunable)
  • • Features: [CPU%, Mem%, Latency, QPS]
MODEL 3 Log Mining

Drain Log Template Miner

Extracts invariant templates from raw logs by parsing variable tokens (IPs, IDs, hex) into <*>.

Tokenize → Regex Slot → Cluster
  • • Parse Depth: Max 4 tree levels
  • • Severity Surge: Catches FATAL & OOM
  • • Strengths: Converts messy text to structured alerts
MODEL 4 Topological RCA

Bayesian Graph Ranker

Ranks root causes using temporal precedence, NetworkX DAG in-degree centrality, and evidence citations.

Score = 0.35•T + 0.25•G + 0.25•A
  • • Precedence Decay: e^(-Δt / 120s)
  • • Graph Direction: Callee → Caller cascade
  • • Honest Uncertainty: Likely vs Inconclusive
